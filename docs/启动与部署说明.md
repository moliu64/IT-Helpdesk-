# IT 运维工单智能体：启动与部署说明

## 本地入口

| 中文入口 | Windows | PowerShell | Linux/macOS | 用途 |
| --- | --- | --- | --- | --- |
| 项目控制面板 | `项目控制面板.bat` | `项目控制面板.ps1` | - | 中文图形面板：一键启动、停止项目、打开网站 |
| 一键部署上线 | `一键部署上线.bat` | `一键部署上线.ps1` | - | 打开控制面板并启动本机源站与 Cloudflare Tunnel |
| 命令行启动 | `start.bat` | `start.ps1` | `./start.sh` | 启动服务但不自动打开浏览器 |
| 兼容入口 | `一键启动.bat` | `一键启动.ps1` | - | 转发到一键部署上线入口 |

启动后：

- 用户入口：`http://127.0.0.1:8787/`
- 后台管理入口：`http://127.0.0.1:8787/backend`，兼容 `http://127.0.0.1:8787/admin`
- 健康检查：`http://127.0.0.1:8787/healthz`

首次运行部署脚本会自动创建 `.venv` 并安装 `requirements.txt`，之后直接复用现有环境。部署脚本会先等待 `http://127.0.0.1:8787/healthz` 成功，再启动 Tunnel；日志位于 `output/`。可使用 `-NoBrowser` 禁止自动打开浏览器，`-SkipInstall` 跳过依赖安装。脚本默认设置 `HF_HUB_OFFLINE=1` 和 `TRANSFORMERS_OFFLINE=1`，模型需预先缓存在本机。

当前 Windows 主机已经配置好 Cloudflare Tunnel 时，可双击 `一键部署上线.bat`，也可直接双击 `项目控制面板.bat`，或执行 `一键部署上线.ps1`，打开中文控制面板。面板会启动 Python 源站和 Tunnel 的独立后台进程；关闭 CMD 或控制面板窗口不会停止服务。需要停止时点击“停止项目”，或执行 `stop.bat` / `stop.ps1`。线上地址默认为 `https://060115.top/`，日志写入 `output/online-app.log`、`output/online-app.err`、`output/cloudflared.log`、`output/cloudflared.err`、`output/control-panel.log` 和 `output/control-panel.err`。需要自定义地址或路径时，可在 `.env` 设置 `HELPDESK_PUBLIC_URL`、`HELPDESK_TUNNEL_CONFIG` 和 `CLOUDFLARED_PATH`；自定义端口使用 `HELPDESK_ONLINE_PORT`。

启动脚本会把实际监听端口的 Python 进程 PID 写入 `output/online-app.pid`，而不是只记录 Windows 虚拟环境启动器 PID，避免停止后残留服务。

控制面板使用 Windows PowerShell 5 兼容写法；如果系统策略阻止脚本运行，入口已带 `-ExecutionPolicy Bypass`，仍需确保 Windows Forms 可用。

## 060115.top 部署入口

线上部署模板位于 `deploy/060115.top/`，包括 Nginx 反向代理、systemd 服务和 Docker Compose 两种方式。建议由 Nginx 负责 HTTPS、域名和后台 Basic Auth，再转发到本机 `8787` 端口。

发布前需要：

1. 将 `060115.top` 和 `www.060115.top` 的 DNS A 记录指向服务器公网 IP。
2. 在服务器安装 Python 3.10+、Nginx，并配置 `LLM_API_KEY` 环境变量。
3. 复制 `deploy/060115.top/.env.example` 为服务器上的 `.env`，不要提交真实密钥。
4. 按 `deploy/060115.top/README.md` 配置 HTTPS 证书和后台认证。

后台包含工单、知识库、运行日志和访问记录。启动前请在 `.env` 设置 `HELPDESK_ADMIN_USER`、`HELPDESK_ADMIN_PASSWORD` 和稳定的 `HELPDESK_SESSION_SECRET`；后台页面与管理 API 会统一要求 Basic Auth，不能在没有认证的情况下直接暴露公网。
